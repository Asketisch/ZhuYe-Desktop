# 运行态集成覆盖清单

本清单区分三个不同的证据：**前端替身**（真实 React，模拟 IPC）、**真实后端**
（Tauri mock runtime + 真命令体）和 **真窗口**（WebDriver 驱动实际 WebView、
IPC、AgentThread 与隔离数据目录）。模型替身仅替代 provider，不替代后端。
命令注册、参数反序列化、空列表或错误返回均不能证明完整业务回路。

这是逐项补强工作的清单，不是已完成声明。具体命令映射见 [COVERAGE.md](COVERAGE.md)，
单次运行结果见 `.test-results/release-review.md`；依赖缺失或实模型限流必须
保持跳过状态，不得折算成通过。

当前子模块 `5f45f0ac` 的 Linux ARM64 隔离窗口复验为 56/57 通过；批准后的
沙箱写入因 Landlock 路径句柄错误失败。视觉层未在该次运行；日志分别为
`.test-results/e2e-window-current-linux.log` 和
`.test-results/release-review-linux-current.md`。其他记录中的 55 项通过来自
包含上游修复的联调快照，不代表当前子模块已通过。

讨论的实时事件、失败终态、历史筛选、transcript 持久化和流水线自定义输入
已直接落在桌面适配层并通过真实 IPC 回归。`TaskList` 明细与 Landlock

## 运行态修复与已知限制

- `TaskList` 的事件元数据包含任务明细，但实际发送给模型的工具结果仅有
  数量和列表 ID，模型无法据此选择或了解任务。`ipc_task_tools_runtime.rs`
  的 `model_can_read_task_list_details` 保留为显式忽略的失败回归；待上游修复
  并升级子模块后启用，不将该项算作通过。
- Autopilot 已改为每次运行独立订阅，普通回合按 submission id、指定 agent 按 side-channel id 关联终态，且在提交前订阅。真实 IPC 回归验证指定 agent 运行期间普通回合完成不会提前终结其历史，两个自动任务交错时快速任务先完成不会终结慢任务，随后两条历史分别回填成功。
- 真实 IPC 回归覆盖 Autopilot 达到迭代上限，以及 token 预算分别在启动配置和绑定会话后热更新时生效并耗尽的失败终态；移除预算后同一会话恢复模型调用。
- Linux Landlock 的上游路径句柄标志写成 `0o200000`，实际不是 `O_PATH`
  (`0o10000000`)。在 aarch64 Linux 容器中，允许的工作区写入和 `/dev/null`
  重定向因此失败；模型替身必须检查 `tool_result.is_error` 和实际输出，不能
  只因请求中出现命令文本就判断成功。已在上游工作树改用正确的 `O_PATH`，
  aarch64 Linux 真窗口 51 项全部通过；桌面仓库当前子模块指针尚未包含该修复，
  正式升级前 Linux 真窗口门禁仍会复现失败。
- LSP 握手期间关闭后，旧实例的事件已被拦截，握手结束后会关闭该实例。
  当前上游握手仍不可安全中断；无响应的服务最长会保留到配置的握手超时。
- 持久化人工输入由外部文件应答后，上游会留下已失效的界面等待器；桌面
  已在工具结束时关闭弹窗，但等待器释放仍需上游修复并升级子模块。
- 人工输入的挂起文件只保存提示和时间，没有会话及工具调用信息；进程异常
  退出后不会自动恢复原回合。相同 context 重新调用工具可消费预写答案，
  已由跨进程真实 IPC 回归验证；自动恢复仍需上游协议与运行时支持。
- 桌面讨论已向编排器注入 recorder，并保证新会话在写入 transcript 前有
  SessionMeta。桌面适配层现在实时转发路由消息、把模型失败与用户取消映射为
  `collab_finished` 终态，并在无筛选历史中排除普通会话；对应真实 IPC
  回归已通过。讨论与子代理运行态取消均有入口。
- 流水线 shell 节点已由桌面适配层透传 `inputs` 并复用上游 BashTool；
  `ipc_pipeline_input_probe.rs` 覆盖模板值落到实际文件。上游后续可收敛
  该适配层。
