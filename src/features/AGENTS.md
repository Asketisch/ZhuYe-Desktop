# src/features/ —— 功能切片层

> **何时读我**：新增或改动功能切片（绑定壳、切片内视图、切片样式与就近测试）前先读本篇——切片怎么组织、往哪里接线，在这里。

## 层定位

功能切片**绑定壳层**：每个切片 = slot 组装壳 + 切片内视图 + 就近绑定测试；控制器/hook 真身住 `src/logic/<slice>/`，纯展示视图住 `src/render/<domain>/`，slot 契约住 `src/contracts/`（v3 分层）；样式几乎每组件一个同名 `*.module.css`，颜色一律消费 `src/render/styles/tokens.css` 标记（规则见根 AGENTS.md「约定」）。

## 层内依赖约定

- 切片之间不互相 import 视图；共享 UI 用 `render/harness/design-system`，共享状态经 `src/stores/`，Tauri 调用只经 `@/utils/commands/{domain}`（见 [utils/AGENTS.md](../utils/AGENTS.md)）。
- 有状态编排一律住 `logic/`，渲染层保持纯展示（`check-render-boundaries.mjs` 守卫）；判定标准是「视图与有状态编排是否分文件」。

## 跨层边界

- 切片对外暴露的只有视图与 hook；跨切片复用一律经 `design-system` / `stores` / `utils/commands` 三个共享面，不走切片直连。

## 层通用规则

1. **控制器/hook 落点**：一律 `src/logic/<slice>/`（v3 迁移后，原 features 内同名 Controller、`hooks/` 子目录、平铺 hook 三种形态的兼容转发已全部退役——如 `terminal/useTerminalController`、`memory/useMemoryController`、`composer/slashCommands` 均以 logic 为唯一真身，测试随真身同目录）。
2. **新切片落点链（本篇独有契约，缺一不可）**：
   1. 建 `src/features/<族>/<slice>/` 绑定壳 + `src/render/<族>/<domain>/` 视图 + `src/logic/<族>/<slice>/` 控制器（测试随真身同目录；族 = conversation/input/harness/workbench/orchestration/telemetry/knowledge/connect/pages，与 render/logic/contracts 三层同构，见各层 AGENTS.md）；
   2. `src/router.tsx` 三处接线：import 视图 → `new Route(` → 挂入 `rootRoute.addChildren([...])`；
   3. `src/utils/i18n/strings/<domain>.ts` 新建文案模块并在 `utils/i18n/strings/index.ts` import + merge（挂载机制见 [utils/AGENTS.md](../utils/AGENTS.md)）；
   4. 视觉基线：`tests/visual/__baselines__/{linux,macos,windows}/` 补 `<route>--{dark,light}.png`（路由 × 双主题，数量以基线目录为准）；
   5. 带测试——`tests/views.untested-slices.test.tsx` 为零就地测试视图（about/apps/debug/dictation/home/mobile/models/prompts/skills）提供行为级兜底，新切片不要进这份清单。
3. **同名 Composer 分叉澄清**：`features/input/composer/Composer.tsx` 是编辑器运行时规范实现；`features/conversation/messages/Composer.tsx` 是一行薄 re-export（`export { Composer } from '@/features/input/composer/Composer'`）。二者同名不同物，改编辑器行为只动前者。
4. **既有切片 README**：sessions / design-system / threads 三 slices 自带 README，进这些切片先读（链接见文末）；其余切片以本篇与根 AGENTS.md 为准。
5. **缓存命中率分两个口径（v1.x）**：会话区折叠胶囊 `harness/shell/session/SessionCapsule.tsx` 与 `harness/shell/Inspector.tsx` 显示的是**本回合**口径（`logic/telemetry/usage/cacheHitRate.ts` 的 `useTurnCacheHitRate`，读 store 的 `tokens.turn`），右侧用量面板 `telemetry/usage/UsageDock.tsx` 与 `/usage` 页显示的是**会话级**口径（后端 `zhuye_session_stats`）—— 两个标签各标各的（`statusPanel.cacheHit` / `usage.turnCacheHitRate` vs `usage.cacheHitRate`），不要用一个标签混指两个口径。命中率一律钳到 `[0, 100%]`。检查器的 Token 构成条四段**互斥**（未缓存提示词 = `input − 缓存命中 − 缓存写入`），别把 `input` 与缓存分段直接相加。
